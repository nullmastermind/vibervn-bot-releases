Cài đặt

Bộ cài chưa được ký bởi nhà phát hành tin cậy; mỗi hệ điều hành sẽ cảnh báo một lần.

Windows 11 22H2+: tải chứng chỉ và file .msix. Tin cậy chứng chỉ một lần trong PowerShell chạy bằng quyền Administrator:
Import-Certificate -FilePath .\ViberVN-signing.cer -CertStoreLocation Cert:\LocalMachine\TrustedPeople
rồi mở file .msix và chọn Install.

macOS 13+: mở file .dmg và kéo ứng dụng vào Applications. Lần đầu macOS sẽ chặn: vào System Settings → Privacy & Security → Open Anyway, hoặc chạy
xattr -dr com.apple.quarantine "/Applications/ViberVN Bot.app"
Nếu vẫn báo ứng dụng bị hỏng, tự ký một lần:
codesign --force --deep --sign - "/Applications/ViberVN Bot.app"

Linux: chmod +x file .AppImage đúng kiến trúc rồi chạy nó.
